Manage deterministic SUT data for local UI and API testing.

These actions are ADMIN only and affect shared SUT test data. Use them before test setup or controlled exploratory sessions.

Reset SUT Data

Restore the compact default seed data: demo users, baseline tasks, labels, issues, and comments.

Clear All Data

This destructive action deletes all tasks, issues, labels, comments, attachments, notifications, and non-admin users. It keeps only the minimum admin account required to sign in again.

Default Demo Data

Load the bundled demodata file with default users, 25 tasks, and 25 issues for broader exploratory and automated checks.

Import Data

Import a controlled JSON data file using the same structure as demodata.json. SQL upload is intentionally not supported from the UI.
